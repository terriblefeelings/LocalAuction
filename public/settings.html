DONATELLO

Посилання або ID приватного каналу донатів.

Потрібен лише для читання каналу. Зберігається локально; у релізі токена немає.

ЯК ПІДКЛЮЧИТИ DONATELLO
  1. Натисніть [ ДОДАТИ БОТА НА СЕРВЕР ] і авторизуйте MonkeBOT на своєму сервері.
  2. У Discord створіть вебхук для каналу донатів: Налаштування каналу → Інтеграції → Вебхуки → Створити вебхук → Копіювати URL вебхука.
  3. Відкрийте Donatello → Налаштування → Інтеграції.
  4. Увімкніть Discord Webhook, вставте URL вебхука, увімкніть «Embedded» повідомлення та надішліть тестове повідомлення.
  5. Скопіюйте ID каналу (права кнопка на канал → Копіювати ID каналу; потрібен Режим розробника) і вставте його вище.
  6. Натисніть [ ПЕРЕВІРИТИ ], а потім [ ЗБЕРЕГТИ ].
WEBHOOK ДОДАТКОВО

Застосунок визначить канал цього вебхука і читатиме його через бота.

ЯК ПІДКЛЮЧИТИ ІНШИЙ WEBHOOK
  1. Увімкніть перемикач [x] УВІМКНЕНО.
  2. У Discord створіть вебхук у потрібному приватному каналі: Налаштування каналу → Інтеграції → Вебхуки → Створити вебхук, скопіюйте URL.
  3. Вставте URL вище. Застосунок знайде канал вебхука.
  4. Додайте бота на сервер цього каналу (кнопка [ ДОДАТИ БОТА НА СЕРВЕР ] вище).
  5. Натисніть [ ПЕРЕВІРИТИ WEBHOOK ], потім [ ЗБЕРЕГТИ ].

Webhook може надсилати embed або звичайний текст — застосунок розпізнає донора, суму й повідомлення в обох випадках.

Повідомлення Donatello у цьому каналі ігноруються, тому джерела DONATELLO і WEBHOOK можна вмикати разом для одного каналу.

MONOBANK ДОДАТКОВО
ЯК ПІДКЛЮЧИТИ MONOBANK
  1. Увімкніть перемикач [x] УВІМКНЕНО.
  2. Отримайте персональний API-ключ на api.monobank.ua (скануйте QR у застосунку Monobank).
  3. Вставте ключ і посилання на банку.
  4. Натисніть [ ПЕРЕВІРИТИ MONOBANK ], потім [ ЗБЕРЕГТИ ].

Monobank опитується раз на хвилину через обмеження API. Донати стають ставками; коментар платежу зіставляється з лотом.

БАНКА ІНШОЇ ЛЮДИНИ
  1. Відкрийте посилання віджета банки: widget.html?jar=…&jarToken=….
  2. Скопіюйте jar (ID банки) та jarToken у поля вище.
  3. Увімкніть перемикач і натисніть [ ЗБЕРЕГТИ ].

Персональний API не бачить чужі банки. Віджет надсилає суму та «Від: ім'я» без коментаря — такі донати зіставляються вручну в «Очікують». Не вмикайте віджет і API для однієї банки — донат задвоїться. Пропущені оповіщення добираються за балансом раз на 5 хвилин.

СТАВКИ

Менші донати ігноруються (для всіх джерел).

ZBIRUK
  1. Додати лот/до лоту: надішліть номер лоту, його точну або схожу назву — 2, Marathon, Marathn, #2.
  2. Додати лот/до лоту з символом: поставте + перед назвою чи номером — + Marathon, +Marathn, +2, +#2. Ті самі варіанти.
  3. Зняти від лоту з символом: поставте − перед назвою чи номером — - Marathon, -Marathn, −2, -#2. Ті самі варіанти. Зняття коштів до 0, більше не знімає.
  4. Іммун: лоти з донатом від 2000 ₴ захищені від зняття коштів — такі ставки чекають підтвердження. Кнопки + / − у списку очікуючих працюють завжди.

# LocalAuction

Локальний аукціон для зборів. Ставки надходять із Donatello, Discord-вебхука
або банки Monobank. Застосунок веде лоти, ставки й історію, рахує таймер, крутить колесо
та відкриває сторінку аукціону у вашому браузері. Усі налаштування — у невеликому вікні.

## Що вміє

- Лоти: додавання, закріплення, коригування суми, видалення.
- Ставки: ручний режим, авто (перша ставка на лот — вручну, далі автоматично) і повний авто.
- Історія: прийняті, очікуючі та відхилені ставки. Кнопка **Додати** зараховує суму до
  існуючого лоту за номером.
- Таймер із правилами зміни лідера, нової позиції та докидання до наявного лоту.
- Колесо: звичайне, на вибування, королівська битва; локальний звук або YouTube.
- Оформлення: теми Default, Retro і Terminal, кожна у світлому й темному варіанті.
- Перевірка оновлень у вкладці **ІНФО**.

## Вимоги

Windows 10/11 x64. Вікно налаштувань використовує WebView2 (у Windows 11 він уже є,
на Windows 10 поставте Microsoft Edge WebView2 Runtime). Сторінка аукціону відкривається
у звичайному браузері.

## Перший запуск

1. Розпакуйте архів і запустіть `LocalAuction.exe`.
2. У вікні налаштувань натисніть **ВІДКРИТИ АУКЦІОН**.
3. Заповніть потрібні інтеграції та натисніть **ЗБЕРЕГТИ**.

## Підключення донатів

### Donatello

1. У Discord: налаштування каналу → **Інтеграції → Вебхуки → Новий вебхук**, скопіюйте URL.
2. У Donatello: **Налаштування → Інтеграції → Discord Webhook**, вставте URL і увімкніть
   **Embedded** повідомлення.
3. Увімкніть режим розробника в Discord, скопіюйте ID каналу донатів і вставте його
   в налаштуваннях застосунку.
4. Натисніть **Перевірити з'єднання**, потім **Зберегти**.

### Discord-вебхук

Джерело для повідомлень інших сервісів у каналі. Вставте URL вебхука цього каналу —
застосунок читатиме повідомлення як embed, так і звичайним текстом.

### Monobank

Увімкніть джерело, вставте `X-Token` з [api.monobank.ua](https://api.monobank.ua/) і
посилання на банку. Нові платежі стають ставками.

## Бот

Кнопка **Додати бота до сервера** відкриває запрошення MonkeBOT у ваш сервер. Токен для
запрошення не потрібен — вистачає прав **Перегляд каналів** і **Читання історії**.

## Ставки

Канал перевіряється кожні 6 секунд, Monobank — раз на хвилину. Текст донату зіставляється
з лотом за назвою, псевдонімом або номером (`#2`).

- **Авто** — перша ставка на лот чекає підтвердження, наступні зараховуються самі.
- **Ручний** — кожна ставка чекає в **Очікують**.
- **Повний авто** — ставки зараховуються одразу, нові лоти створюються автоматично.

У списку очікуючих є **Прийняти**, **Відхилити** та **Додати** (зарахувати до лоту за номером).
Ставки нижчі за мінімальну ігноруються.

## Таймер

- **Зміна лідера** — додає час, лише якщо лідер уже був.
- **Нова позиція** — для нового лоту після першого профінансованого.
- **Додати до наявного** — коли лот уже має ставки.
- **Обмеження** — максимум часу; `0` означає без обмежень.

## Колесо

Три режими: звичайний, на вибування та королівська битва. Можна додати медіа в центр,
увімкнути локальний звук або YouTube-посилання. Праворуч працює конструкт Lumasik —
його можна вимкнути в **Оформленні**.

## Дані

`config.json`, `state.json` і `log.txt` зберігаються в `%APPDATA%\LocalAuction`.
Порт за замовчуванням — `48974`; інший можна задати змінною `LOCALAUCTION_PORT`.

Ліцензії та подяки — у файлі `LICENSES.txt`.
